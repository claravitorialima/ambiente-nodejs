# ambiente-nodejs

Projeto simples de ambiente Node.js com TypeScript.

## Sobre 🛰️

Este repositório apresenta um ambiente básico para executar código TypeScript usando Node.js. Ele usa `tsx` para desenvolvimento com recarga e `tsc` para compilação.

## O que faz ❓

- Exibe mensagens no console com `console.log`
- Demonstração básica de um arquivo `src/app.ts`

## Estrutura 🏛️

- `src/app.ts` - arquivo principal com código TypeScript
- `package.json` - dependências e scripts
- `tsconfig.json` - configuração do compilador TypeScript

## Scripts úteis 📝

- `npm run dev` - executa `src/app.ts` em modo watch com `tsx`
- `npm run build` - compila o projeto com `tsc`
- `npm start` - executa o código compilado"# ambiente-nodejs"
